Box: 8 cores (DO-Premium-Intel), 31 GB, local loopback; locust and the collector share one host, so these numbers are not a network result.

Locust drives simulated agent hosts at the collector (uvicorn plus the database, same host). Pass means ingest p95 under 2 s. Arrival is `staggered` (each host enrols and sends its first bundle at a random offset in the first interval, so the offered load is steady at hosts/interval posts/s) or `herd` (every host enrols and posts as it spawns: a 10 s ramp at 50 hosts/s for 500 hosts). Read the rate, not the host count: FLEET.md's daily timer with a 2 h random delay puts 2,000 hosts at 0.28 posts/s, while 500 hosts every 60 s is 8.3 posts/s, about 60,000 daily hosts. `Little ratio` is the achieved rate over the Little's law expectation hosts / (interval + mean response); outside 0.9 to 1.1 the run lost requests and is a measurement defect, not a capacity result (None: run shorter than two intervals, not evaluated). `parse slots` is how many bundles the collector parsed and stored at once; `insert` is the bulk-insert strategy (`pages`: multi-row INSERT ... VALUES, the default; `executemany`: one parameter set per row; `-`: row predates the knob); `keep` is the per-host retention passed to the collector (scans kept per host; the product default is 12, and pruning starts only once a host has posted more than that).
