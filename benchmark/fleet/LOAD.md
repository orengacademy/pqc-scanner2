Box: 8 cores (DO-Premium-Intel), 31 GB, local loopback; locust and the collector share one host, so these numbers are not a network result.

Locust drives simulated agent hosts at the collector (uvicorn plus the database, same host). Pass means ingest p95 under 2 s. Arrival is `staggered` (each host enrols and sends its first bundle at a random offset in the first interval, so the offered load is steady at hosts/interval posts/s) or `herd` (every host enrols and posts as it spawns: a 10 s ramp at 50 hosts/s for 500 hosts). Read the rate, not the host count: FLEET.md's daily timer with a 2 h random delay puts 2,000 hosts at 0.28 posts/s, while 500 hosts every 60 s is 8.3 posts/s, about 60,000 daily hosts. `Little ratio` is the achieved rate over the Little's law expectation hosts / (interval + mean response); outside 0.9 to 1.1 the run lost requests and is a measurement defect, not a capacity result (None: run shorter than two intervals, not evaluated). Rows from PR #92 (19-column format, 300-finding bundles) are in [LOAD-pr92.md](LOAD-pr92.md). The box was shared with unrelated work, so the load average column matters when reading a row. Postgres rows ran against a local `postgres:16-alpine` container.
